Holds & Arcs Trainer: offline app

What's in this folder
  index.html             the trainer
  sw.js                  keeps the app on your device for offline use
  manifest.webmanifest   lets the device install it as an app
  *.png                  app icons

Put it online once (pick one)
  A. Netlify Drop, easiest from a laptop
     1. Unzip this folder.
     2. Go to app.netlify.com/drop and drag the folder onto the page.
     3. You get a web address straight away.

  B. GitHub Pages, works from a phone browser
     1. Make a free GitHub account and create a new public repository,
        for example "holds-arcs".
     2. Add file > Upload files, and upload every file in this folder.
     3. Settings > Pages > Deploy from a branch > main > / (root) > Save.
     4. After a minute the address is https://YOUR-NAME.github.io/holds-arcs/

Install it on the phone or iPad
  1. Open the address once with signal.
  2. iPhone/iPad: Safari > Share > Add to Home Screen.
     Android: Chrome > menu > Install app.
  3. Wait for the green "Works offline" label at the top of the page.
     From then on it opens and flies in airplane mode.

Updating
  Upload the new files to the same place, then open the app once with signal.

Note
  Anyone with the address can open the page. It contains procedure data
  from your Jeppesen charts and references to the ALS Operations Manual,
  so keep the address to yourself.
  Training use only. Chart data is from cycle 13-2026 and is not for navigation.
